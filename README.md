# 川渡りパズル / River Crossing Puzzle

ブラウザで遊べる日本語の教育用パズルです。HTML・CSS・JavaScriptのみで実装し、外部ライブラリ・フォント・画像配信への依存はありません。

## 遊び方

1. トップ画面でLEVEL 1〜5を選択します。
2. 練習モードまたはチャレンジモードを選びます。
3. ボートと同じ岸にいるキャラクターをタップして乗せます。
4. ボート上のキャラクターをタップすると降ろせます。
5. 「川を渡る」で移動します。移動できないときは理由が表示され、手数・配置は変わりません。
6. 全員が右岸へ到着するとクリアです。最後の乗客は自動的に降ります。

練習モードでは不正な操作の理由を中央に表示し、「閉じて続ける」で同じ状態から再開できます。チャレンジモードでは一度の不正な操作でGAME OVERになり、同じ問題・モードで再挑戦できます。定員超過・空のボートでの出発・操作者の不在も不正な操作に含みます。次のレベル・リセットでは現在のモードを維持し、問題選択からは選び直せます。ベスト手数は従来どおり両モード共通です。

時間制限はありません。ベスト手数は端末のブラウザに保存します。保存を利用できない環境でも遊べます。

## GitHub Pagesで公開

このリポジトリをGitHubにpushし、リポジトリの **Settings → Pages** で **Deploy from a branch** を選択します。公開するブランチ（例：`main`）と **`/ (root)`** を選んで保存してください。

ビルドは不要です。相対パスを使用しているため、リポジトリ名付きのURLでも動作します。`.nojekyll` を配置しています。

## ローカルで確認

ES Modulesを使用するため、ファイルを直接開く代わりにHTTPサーバーを起動してください。

```sh
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000` を開きます。

## テスト

Node.js（18以降）で、追加パッケージをインストールせず実行できます。

```sh
npm test
# または
node --test tests/*.test.js
```

幅優先探索で全レベルの解法を発見し、実際の移動関数で最後まで再生して検証します。最短手数はLEVEL順に **3・7・11・11・17手**。禁止条件、運転者、定員、出発側・到着側の判定もテストします。

Chromeでチュートリアルのクリア、LEVEL 5の初回移動、リセット、横幅320・375・768・1280pxでの横はみ出しを確認済みです。iPad/iPhone実機での確認は未実施です。

## 判定の仕様

- 乗り降り中は、ボートに乗っている人も停泊中の岸にいるものとして扱います。
- 出発時に、乗客を反対岸へ移した後の左右両岸を判定します。
- 夫婦・人数・家族の条件は指定どおり岸に適用し、ボート内に追加の禁止条件は設けていません。
- 不正な移動では手数も位置も変化しません。

## ファイル

- `index.html` — 問題選択・プレイ画面
- `style.css` — レスポンシブ表示と移動アニメーション
- `engine.js` — 問題定義と独立したルール判定
- `app.js` — 操作・画面描画・記録保存
- `tests/engine.test.js` — 解法探索とルール検証
